# constitution.md - Programming languages

Hands on python implementation of the parts of a compiler for the Programming Languages subject. Including lexical analyzer, sintactical analyzer or parser, translation or interpretation. The goal is to implement each step of the compiling process.

1. **Stack:** Python, pytest for tests
2. **Learning-focused:** The whole idea of these exercises is to get hands on experience in the implementation of these kinds of systems. Therefore, it is the student's responsibility to think through the problems and write the core code of each submission. Agents should only help doing testing and documentation work, clarifying doubts about already existing code, and only if the student explicitely asks it, and if it is really a repetitive task without much learning value help with code generation.
3. **Input language** The programming language used as input code for submissions is Lua 5.5
